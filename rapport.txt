Rapport TP Git - Analyses Experimentales
Git est un outil indispensable pour sauvegarder l'historique du code.
GitHub permet de stocker le projet en ligne et de collaborer.
J'ai appris a cloner un depot dans Google Colab avec !git clone.
J'ai cree une nouvelle branche 'develop' avec la commande !git checkout -b develop.
Cette branche permet de travailler sans toucher a la branche principale 'main'.
Projet : Analyse de resultats de laboratoire avec Python (pandas, matplotlib).
Les commandes importantes : git add, git commit, git push, git branch.
